<h2>📖 Overview</h2>

<p>
  <strong>Sync-Path</strong> is a full-scale interactive visualization engine designed to master 
  <strong>Data Structures, Algorithms, and Interview Patterns</strong> through real-time execution.
</p>

<p>
  Unlike basic visualizers, Sync-Path simulates step-by-step execution flow, pointer movements, recursion stacks,
  dynamic programming table construction, heap balancing, graph traversal animations,
  and Big-O benchmarking diagnostics.
</p>

<h2 id="installation">🚀 Installation</h2>

<pre>
<code>
# Clone Repository
git clone https://github.com/JitendraSrivastava12/sync-path.git

# Enter Project Directory
cd sync-path

# Install Dependencies
npm install

# Start Development Server
npm run dev
</code>
</pre>

<p>
  Application runs at:
  <code>http://localhost:5173</code>
</p>
