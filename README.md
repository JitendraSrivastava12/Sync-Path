<h2>📖 Project Overview</h2>
<p>
  <strong>Sync-Path</strong> is a professional-grade platform designed to demystify complex Data Structures and Algorithms. Unlike basic visualizers, Sync-Path provides a <strong>System Terminal</strong> experience, showing real-time logic flows, variable states, and Big O benchmarks.
</p>

<h2 id="installation">🚀 Installation Procedure</h2>
<p>To set up the Sync-Path engine on your local workstation, execute the following commands:</p>

<pre>
<code>
# 1. Clone the repository
git clone https://github.com/JitendraSrivastava12/sync-path.git

# 2. Navigate to project root
cd sync-path

# 3. Install dependencies
npm install

# 4. Launch the developer engine
npm run dev
</code>
</pre>

<p>The application will be accessible at <code>http://localhost:5173</code>.</p>
